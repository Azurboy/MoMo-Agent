# Sticker 保存与生成等待修复 · 2026-11-06

已完成的生活插画作为独立成品保存。转录重新同步、正文修订、说话人标签与本人归属变化、定位快照变化和生图订阅不可用，不撤回既有图片，不自动重新收费生成。明确删除 sticker 或其来源录音仍发布删除事件并清理对应资产。

来源复核只更新尚未提交的待生成简报；已接纳的请求保持单次提交与结果落盘。未知执行结果不自动重投，已有 invalid/deleted 时段继续阻止重复生成。手机本地读取与生图能力解耦，保持 workspace 目录隔离；网络 API 仍逐请求鉴权。

每段密集对话结束约 10 分钟，且附近待转录范围清空、相关总结不在执行中，即可入队。取消等待 2/3/4/6 小时墙钟批次边界；旧 interval_hours 字段保留用于旧客户端兼容与首次启用边界，不再作为生成延迟。聊天空闲准入与原有内容密度判断保留。设置改为直接说明实际等待条件。

## 原因与恢复核查

实际历史快照的只读对比证明：说话人标签前缀和本人归属变化可以改变旧 semantic_hash，旧 reconcile 因而将已完成记录置为 invalid，再经 tombstone 和 prune_assets 删除两端资产。恢复用的来源快照与简报也被清空。此机制导致资料重新同步后，已下载图片仍会消失。

本轮仅在隔离副本上验证重新同步与队列扫描，不调用生产生图。已删除历史时段保持原尝试次数。现有图片、数据库与手机缓存已先保存独立副本。失效原图仅凭哈希和响应 ID 无法恢复；未找到原始字节时不创建替代图片、不重新提交生成。
