# 录音详情播放器交互（0.4.7）

## 问题与边界

用户反馈手机录音详情的播放器只能看，点击、拖动不可靠。旧版模拟器回归已复现：首次播放前点击波形不会定位。

共用 AudioPlayerCard 存在三处原因：未激活的预览禁用了定位；波形只注册拖动，没有点击定位；正在执行定位时直接丢弃后续操作。播放控制器又把定位过程中暂时暂停的原生状态当作用户的暂停意图，连续定位可能意外停止播放。

## 实现

采用标准交互档，保留点阵波形、时间与既有卡片外观。SwiftUI 持有预览位置，UIKit 的方向手势先判断水平意图，垂直拖动交给阅读滚动。点击和拖动结束提交定位，取消手势不提交；拖动时固定本次时长，避免播放时钟或元数据刷新拉动指针。触控输入和可调整的辅助功能共用同一个定位入口。

首次播放前定位会校验真实音频并静默选择位置，不激活 AVAudioSession。播放意图与原生准备状态分开保存；后续定位、暂停或继续通过原有 generation 替换旧指令，保留实际播放或暂停意图。维持缺失区间、末尾、来源变更、音频租约和清理校验。

修改覆盖录音详情、时间段详情及引用共用的播放器，不改动录音采集、转写、同步、配对或 sticker 资源。版本为 0.4.7。

- 两项 UI 旅程通过，覆盖未播放时点击、暂停拖动、播放拖动后的真实时钟推进、从波形区域上下滚动，以及录音来源保持。
