# 历史插画补齐与地图卡片稳定性 · 2026-11-07

## 行为

开启生活插画后，扫描已同步、已结束且已完成转录的密集对话，包括首次启用之前从未生成的历史录音。没有当天新录音也会继续处理积压。旧 active_from 字段保留兼容既有数据库，不再截断历史准入。优先处理最近的待生成对话，避免新录音被历史积压压住。

已有 ready、invalid、deleted、needs_review 等时段的重叠保护保留；不会重绘此前已生成后丢失的图片，也不会重投结果不明的请求。关闭开关立即阻止新准入，原有十分钟安静期、待转录范围和单次提交约束保留。

地图沿用现有样式与原生 MapKit 手势。缩放/拖动期间固定卡片布局使用的投影快照，实时更新地图点和连线；regionDidChange 后一次提交新的布局和可见范围。卡片身份继续使用地点/插画 ID，连续缩放不反复切换完整/紧凑卡片。

去掉按 120/700 毫秒猜测相机操作结束的逻辑，改用原生区域变化回调与已有手势识别器状态识别用户操作，避免连续捏合后“适应全天行程”又被标记成自定义视野。AppKit 额外从原生 scrollWheel 入口识别滚轮移动，确保能够复位。没有新增手势识别器或定时动画。

## 复现与验证范围

常规 profile，保留当前配色、文字与控件语义；iOS 18 / macOS 14 为最低部署版本。实际 Mac 旧版地图放大后可见卡片位置跳变与卡片集合变化，原布局在每个可见区域回调重新执行避让与筛选。

在隔离数据库上扫描实际已同步来源，新增 57 段此前从未入队的历史对话；原有 57 条队列记录的状态、请求 ID、尝试次数和图片哈希完全不变。隔离扫描没有调用生图。

回归覆盖历史补齐、关闭开关、防重与结果不明保护；地图覆盖 180 帧缩放/中途反向投影、布局身份与尺寸稳定、手势结束提交、重置视野，以及模拟器真实连续缩放、捏合、拖动、明暗外观和图片阅读。

只使用默认字号，遵循项目取消大字号测试的要求。完整 VoiceOver 朗读、低端真机帧率与系统 Reduce Motion/Reduce Transparency 矩阵未据此宣称验收；本次没有新增空间动画或透明材质。UI 质量评估限于本轮地图交互修复，不把既有整体界面标为已达到完整设计评分。
