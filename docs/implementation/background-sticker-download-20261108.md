# 后台插画下载与持久保存 · 2026-11-08

0.4.4 补上了转录上传，但插画仍只随前台轮询下载，退后台会取消同一下载任务。Mac 生成后的结果可能等到再次打开 App 才落到手机。

## 行为

- 复用录音后台投递的有限执行窗口：来源有变动时上传，然后同步插画清单、原图和缩略图。后台只读取已生成结果，不请求重画。
- 在每个工作空间的既有同步日志中保留图片同步需求和未完成状态；转录上传回执不能清除图片同步需求。开启生成时继续申请后台检查，覆盖 Mac 的对话安静期、总结排队和之后才完成的生成，而非看到一次空队列就停止。
- 停止前台轮询不取消仍由后台任务持有的下载；系统过期或所有连接持有者结束后才取消。图片完整校验并写盘后才确认完成。下载中断不推进清单游标，已经校验保存的文件会在重试时复用。
- 待上传、待生成、未完成图片和网络失败最早五分钟后申请下一次系统任务；健康状态最早十五分钟后检查。保留已有更早请求，新的紧急工作可提前请求，不因持续录音不断延后。
- 一次成功同步仍可保留未来检查需求，向系统报告本轮成功，避免把等待 Mac 生成误报为后台任务失败。
- 图片和索引在 iOS 使用与现有手机资料一致的[首次解锁后文件保护](https://developer.apple.com/documentation/foundation/fileprotectiontype/completeuntilfirstuserauthentication)，支持锁屏后保存和读取。读取已有索引失败会保留原文件并报错，不再回退成空索引覆盖原数据；明确删除的同步语义保留。

## 验证

13 项图片与缓存测试通过，覆盖后台下载退出前台、原图/缩略图落盘与离线恢复、过期后只补缺少文件、鉴权失败保留已存图片、设置变化不能确认被中断的下载、索引读取失败不覆盖原数据，以及既有分页、防重和哈希校验。

30 项模拟器集成测试通过，覆盖后台授权生命周期、来源上传与图片需求分别确认、需求跨进程恢复、新变化不被旧回执清除、一次成功后仍安排未来图片检查且不循环空转。全部使用默认字号，无界面样式改动。

## 边界与交付

复用 Apple 的 [Background Tasks](https://developer.apple.com/documentation/backgroundtasks/) 机制。最早请求日期不等于系统执行时刻；没有新增 APNs 配置依赖或即时静默推送，不能承诺 Mac 生成后立即唤醒锁屏手机。真机系统调度、网络与电量表现仍需设备安装后验证。

手机版本 0.4.5，包含此前的图片保留、地图与后台上传修复。iPhone / 内嵌 Watch Release 构建、版本/资源预检与完整签名核验通过，覆盖升级包已准备；手机当前不可连接，尚未安装。Mac 继续使用 0.4.3，无服务端协议变更；已有原图不重新生成。
