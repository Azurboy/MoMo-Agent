# 生活插画行程地图

2026-11-05，分支 `feat/life-illustration-journey-map`，版本 `0.4.0`。范围为代码、真实 Codex 场景提炼、已有贴纸复用、iPhone 模拟器验收和 Mac arm64 构建。

## 数据与同步

- 到访来源同时启停 `CLVisit` 与显著位置变化监测。后者接受 500 米内精度，按 150 米与 300 秒联合去重。保留七天窗口，最多 1800 条，优先移除最旧途中定位点。关闭来源及撤销系统授权会停止两项监测并清除本地记录。
- 仅完整、精度不超过 200 米、与插画窗口重叠至少五分钟的停留可确定地点。主地点选重叠时间最长的停留。途中定位点独立作为轨迹依据。
- 场景提炼单次输出 `SUMMARY` 和 `BRIEF`，旧纯文本输出继续可用。摘要保持讨论、尝试、未完成与计划的事实边界，原始转录仍由现有来源读取链路保留。
- 队列为已有数据库幂等增加摘要、坐标、停留时间与轨迹字段。轨迹限制为 64 点，优先保留停留及首尾。服务端保留设备、来源记录与修订依据，客户端仅接收展示字段。
- 来源修正、删除和授权撤销会撤回插画、清除位置与摘要、替换历史清单事件为墓碑并清理图片。滚动窗口自然过期沿用原有保留语义。
- Swift 解码兼容旧缓存缺失字段，校验坐标、时间、停留边界和轨迹数量。沿用鉴权 API、增量游标、图片 SHA-256 校验及工作区缓存隔离。

## 三层体验与订阅状态修正

- 底部邮票条继续使用既有 104×52pt 卡片和透明贴纸。点击后展示当天地图。
- 地图使用真实 `MKMapView`（平面默认色彩强调、隐藏商业 POI，明暗两态保留绿地、水系与道路色彩饱和度，暗色采用夜色蓝绿提亮与暖白路线外描边，避免灰暗或死黑）。沿街步行路线经拐角柔化与自然曲线拟合呈现，途中时间胶囊贴合曲线展示出发与到达时刻，去除所有系统免责声明与冗余说明文案。
- 停留点使用分色鹅卵石徽章（暖珊瑚、河岸青、钴蓝等），卡片左右交替避让停留点与彼此，通过柔和 S 形贝塞尔曲线与圆点锚定真实坐标，不再使用直线射线纸楔。一天记录较多时按可用高度分页访问。
- 详情展示完整纪实摘要、地点与时段、上一程出发与到达时刻、转录跳转、分享和删除。iPhone 按天横向翻页，原生图片缩放支持 1–5 倍捏合和双击 1↔2.5 倍。
- Mac 时间线复用同一地图和卡片，详情使用原生 `NSScrollView` 捏合与双击缩放，并提供前后翻页。
- 修正「已登录 Codex 订阅仍显示登录提示」问题：`LifeIllustrationStore` 区分未配对、同步中、临时不可用与真实未登录状态，避免未同步完成前误报为 `not_signed_in`；在网络恢复回调及进入设置页时立即触发刷新；后端 `CodexIllustrationGenerator.availability()` 支持直接识别 `hermes/auth.json` 已登录的 Codex 订阅并区分临时异常与未登录。

## 样本与验收

样本、截图和详细日志保存在 `life_ill_screenshots` 目录。三张原始 PNG 与缩略图逐字节复用先前 Codex 生成结果，摘要来自实际登录 Codex 的 `prepare()` 调用。北京三个停留点及途中定位点均为虚构验收资料。

- Python 插画测试 37 项通过，覆盖旧库迁移、解析、地点归因、途中定位点、数量上限、撤销清理及 Codex 登录可用性判定。
- Swift `MoMoAgentClientTests`（含 `LifeIllustrationTests` 7 项）、`LifeIllustrationJourneyLayoutTests` 3 项与 iPhone 明暗 `LifeIllustrationJourneyTests` 全部通过，Mac `arm64` 构建通过。

本轮定位采集由代码与模拟器链路验证，实机跨地点后台唤醒与耗电仍需设备验证。
